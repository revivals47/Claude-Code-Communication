| 7 | **mgen06-10 の既存 JSON が当時なぜ 0 件になったか** | **歴史的に不能**(第 3 の不能)。当該 path が今は発火せず、metadata が同一の mgen05/mgen11 は正常 ⇒ **原因は当時の tool 版か当時の metadata にあり、現存 file には残っていない** |

**不能の 3 種別を分ける**(PRESIDENT (56) + 本日の追加):
- **資源的に不能** — 入手すれば閉じる(#1 Rev 1 の image / #2 別個体の disc)
- **機構的に不能** — 手法を変えないと閉じない(#4 runtime 観測が要る)
- **歴史的に不能** — **過去の状態が現存 file に残っていない**(#7)。**入手でも手法でも閉じない**

**重要**: 上の 1 と 2 は「恒久の限界」ではない。**Rev 1 の image / 別個体の disc が入手できれば閉じる**。「不能」と「永久に不能」を混ぜない。

## 3.5 **remake 側の HONEST GAP**((112))

**原盤**: `0x800A46DC` は load 失敗を **検出可能**(v0 = 0)だが、**caller が直後に `move v0, s1` で上書きして検査しない** ⇒ **失敗時 buffer は 1 byte も書かれず、前の内容のまま 6 section が parse される**。
∴ **file が開けない map に入ると、直前の map の buffer から 6 section が読まれる**。

該当: **(B) `yaka01`/`yaka21`**(表 entry 在り / file 無し)/ **(C) `yaka25` の idx 65**(dir5 では開けない)。
**(A) `mgen17`** は**そもそもこの経路に入らない**(名指しできない)= **別の結末**。

**remake**: map ごとに JSON を読むので、**file が無ければ空か例外**。**前の map の buffer を持たない**。

⇒ **原盤 = 直前 map の残骸が見える / remake = 何も出ない(または skip + log)** = **忠実性の逸脱**。

> **再現の要否は「未判断」。**「再現しない」と書くと判断済に見える。
> これは**原盤の bug 相当の挙動**で、再現すべきかは別の判断。

## 6. 確立した規範(本 session で追加・実証されたもののみ)

1. **5 欄書式** + 走査範囲欄に **根拠種別 4 択(機構 / 位置 / 統計 / 慣習)** — **格上げにも使える**: worker2 が `hasDigimon == (flags & 0x80)` を 244/0 で全数照合し、**慣習 → 機構**へ上げた(**本日初の格上げ**)。4 択は「倒れやすさの予告」だけでなく**両方向に動く** — **本日倒れた根拠はほぼ全部が位置か慣習。機構由来は 1 つも倒れていない**
2. **通番**: 各便に番号、受け手は返信冒頭に受領した最後の番号。**relay 欠落と送信拒否の両方を捕まえる**
3. **message は file 経由 + 二重引用符つき `$(cat …)`** — 二重引用符は load-bearing(無いと最初の 1 語に切り詰められ、**成功したように見える**)
4. **中継区分** `[逐語可]` / `[要約のみ]` / `[転送不可]`。区分なしは `[要約のみ]`
5. **中継 checklist(送り手)**: この便で新たに渡る事実を列挙 → 受け手が独立に測る量と突合 → 「渡さない」と書く前に過去便を grep。**動機説明が最も漏れる**
6. **着手宣言(受け手)**: これから独立に測る量を 1 行で先に宣言し、その量について数値を受け取らないよう要求する
7. **残余 bucket は列挙し損ねたものを吸い込む** — 「どちらでもない」は常に 2 つの意味を持つ
8. **母数は「file が在る」でなく「中身が対象である」で数える**。名前は種類の証拠にならない
9. **効率で検定を潰さない** — 作業は重複を避け、**検定は重複させる**
10. **上位の指示でも、根拠が失効していれば実行しない**。**worker の自己訂正は単独で上申**
11. **限界を書くことと、その限界を結論に反映することは別の作業**(穴を指摘する文と穴に落ちた文が同一報告に同居した実例)
12. **限定欄と本文を突き合わせる工程を持つ** — 両方向に失敗する(限定より本文が強い / 本文より連鎖欄が弱い)
12-b. **節間も突き合わせる** — 同一 doc の中で**節ごとに更新時刻が違う**。§4 を更新して §2 を放置した実例(PRESIDENT が読んで発見)
12-b2. **doc の節間の食い違いは、整形の問題ではなく測定の問題である可能性が高い** — 見つけたら「直して揃える」のでなく**「なぜ 2 つの値が出たか」を測る**。実例: §2 と §4 の (p1) が 51,168 対 51,944 → 測ると **worker3 が 705 byte 除去しすぎ**と判明し、被覆率が 36.80% → 36.73% に動いた

14. **「領域の性質」と「指標への影響量」は別の量**

## 13. **第 5 型の対 — 理由が「数値」か「機構」か**（worker2 #58 返信 / worker3 #175、PRESIDENT (322) で正式登録）

第 5 型（**定義変更による見かけの改善**）は「値が動いたが測っている対象が変わった」を捕まえる。
