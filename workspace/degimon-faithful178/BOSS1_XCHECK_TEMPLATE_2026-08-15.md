## ★突合を出す前に、この 5 欄を埋める★(空欄があれば突合を出さない)

```
【1】測定値      : 値そのもの(例: map cell の低位 byte = 179)
【2】その値の書き手: ★誰がその値を書いたか★ — 書き手が複数あるなら全部列挙
                   ★分からないなら「不明」と書く(空欄禁止)★
【3】表の適用範囲  : その表は ★どの書き手の出力を記述しているか★
【4】【2】と【3】の交わり: 交わりが空なら ★突合してはいけない★
【5】不一致の意味  : 一致/不一致が何を意味するか(先に書く)
```

```

【2】★region に入るたびに header の 0xFB が書く★(全 region・site 255 件)

```
