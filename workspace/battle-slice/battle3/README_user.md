2. ゲームを**戦闘に入れる**（相手は誰でもいい）。
3. 別の端末で **`~/Documents/Claude-Code-Communication/workspace/battle-slice/battle3/run.sh`** を実行する。
4. 画面に「準備できました」と出たら、**そのまま戦う**。攻撃を受けるたび 1 行ずつ出る。
5. **10 行くらい出たら Ctrl-C** で止める。それで終わり。
