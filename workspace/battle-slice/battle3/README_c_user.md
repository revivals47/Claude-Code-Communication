# やること（4 行）

1. **DuckStation を起動**して、いつものセーブでゲームを始める。
2. 端末で **`~/Documents/Claude-Code-Communication/workspace/battle-slice/battle3/run_c.sh`** を実行する。
3. 「準備できました」と出たら、**戦って 1 回 勝つ**。（負けたら、もう一度 戦って勝てば大丈夫）
4. **勝ったら、もう 1 つ端末を開いて同じ場所の `stop_c.sh` を実行**する。それで終わり。

---

- **ボタンを押す必要はありません。** ふつうに戦って勝つだけです。
- **`stop_c.sh` で止めてください。Ctrl-C では止まりません。**
- ゲームの中身は**読むだけ**。書き換えない。セーブも壊さない。
- つながらない時は、DuckStation 側で GDB サーバ（ポート 2345）が有効か見てほしい。
- 結果は `resultc_<日時>.txt` に残る。**その 1 ファイルを渡してもらえれば足りる。**
