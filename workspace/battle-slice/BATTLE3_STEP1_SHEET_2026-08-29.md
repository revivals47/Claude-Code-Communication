## どれと戦うかで 判別できるかが決まる（**発数より 組み合わせが効く**）

`倍率 = eff_sum / 30`。neutral（倍率 1.000）と **予測 range が重ならない**のは:

> **倍率 ≥ 1.333 または ≤ 0.733** → **1 発で ★必ず★ 判別できる**（range が重ならない）
>
> **★2026-08-30 追記★**: 重なる側でも **当たれば 1 発で判別できる**。
> 実際 x1.167 で `78` / `70` が出て、どちらも表なしの上限 `69` を超えた ⇒ **1 発で判別した**。
> **「判別できない」は「保証されない」の意味であって「決してできない」ではない。**

全 1267 組（7 element × 181 species）の内訳:

| | 倍率 | 組数 |
|---|---|---|
| **1 発で判別できる** | x0.400 / x0.500 / x0.567 / x0.633 / x0.667 / **x0.733** / **x1.333** / x1.500 / x1.667 / x1.833 / x2.000 | **452** |
| 1 発では **保証されない**（当たれば判別できる） | x0.833 / x0.900 / **x1.000** / x1.067 / **x1.167** | 815 |

**選び方** = 防御側の属性 3 本と技の element で表を引き、**M/30 が 1.333 以上 か 0.733 以下**の相手を選ぶ。
（表 = `data/battle_attribute_matrix.json`。`m[i] = attr[i]==0xFF ? 10 : matrix[element*7+attr[i]]`、`M = m0+m1+m2`）
